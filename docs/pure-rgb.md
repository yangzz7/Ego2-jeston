# 纯RGB画面

电脑照常运行 `bash ~/jetson-sensia.sh`，在启动面板选择 **纯RGB画面**，
选择 1–4 台相机后点击启动。支持任意部位组合，不要求选择胸部。

每台相机一行，显示左右两幅按该相机 SN 参数增强的 RGB 画面。
底部时间轴可查看当前 Rerun 会话内保留的历史画面；没有骨架、标定板、
轨迹、点云或 IMU 图表。本模式仅预览，不启动录制面板、不写采集数据集。
其他模式的算法和录制行为保持不变。

`configs/rgb.yaml` 单独控制采集目标帧率、显示上限和 JPEG 质量。
初始为 30 FPS / 30 FPS / 85；这是上限，实际取决于相机协商帧率、ISP、
编码、传输及电脑显示性能。原有模式的 15 FPS 配置不变。

每台相机独立运行：USB RAW → 单槽最新完整双目帧 → 现有显示 ISP →
JPEG → 同一个 Rerun。没有手势或定位推理，也没有重复的算法 RGB 转换。
复用已部署的 CUDA 显示 ISP，GPU 不可用时沿用其 CPU 增强回退机制。
增强参数缺失或运行失败会报告错误并停止，不会悄悄替换为未增强画面。

时间轴是所有相机共享起点的主机接收时间，左右目同一时刻；
它不代表多台相机已经硬件同步，也不是严格的曝光时间。
预览跟不上时丢弃旧的待显示帧，保持最新画面。Ctrl+C 正常结束预览。

诊断：在 Jetson 项目目录执行 `.venv-jetson/bin/python -m ego2.multi_vio
--mode rgb --no-setup --no-viz --seconds 10`，使用已保存的相机选择，
仍执行 ISP 但不打开 Rerun，输出每台相机处理帧数和耗时。
